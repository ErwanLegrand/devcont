# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public issue.** Instead, send an email to:

```
security@example.com
```

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue, if possible.
- The potential impact of the vulnerability.
- Any suggested mitigations or fixes.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |

Only the latest release receives security updates. Users are encouraged to stay on the most recent version.

## Response Timeline

- **Acknowledgement**: Within 48 hours of your report.
- **Initial assessment**: Within 5 business days.
- **Resolution target**: A fix or mitigation will be developed within 30 days of confirmation, depending on severity and complexity.

We will coordinate disclosure with you and credit you for the report (unless you prefer to remain anonymous).
